# Configs

A run without a committed config did not happen (AGENTS.md section 6).

```
configs/
├── train/   one YAML per training run family, e.g. stand_g1_dex3.yaml (P05)
└── eval/    one YAML per scenario and split, e.g. s4_unseen.yaml (P23)
```

Every file that names a physics preset must set `physics: isaacsim_physx`; `tests/test_package.py`
fails otherwise. Configs record `num_envs`, seeds, iteration budgets and randomization ranges, and `scripts/evaluate.py --config FILE` records the file's SHA256 in the result JSON
(`run.config_sha256`, #52).

| Config | Run family | Status |
| --- | --- | --- |
| `train/stand_g1_dex3.yaml` | `KitchenBot-Stand-G1-Dex3` balance policy, RSL-RL PPO, 1024 envs, 1,500 iterations | Untested draft (#46); #5 runs it |
| `eval/s0_seen.yaml` to `eval/s4_unseen.yaml` (ten files) | one evaluation scenario and split: `physics: isaacsim_physx`, `num_envs` (100 for S0 to S3 seen, 50 otherwise; `scripts/evaluate.py --config` runs with it when `--num_envs` is not given, #78), first/last/count of the seeds, the evaluator defaults (own policy, Dex3, floating base) and the section 2 randomization ranges of `kitchenbot.scene.randomization` | Generated by `scripts/make_eval_configs.py` (`--check` diffs), not hand-edited (#52); the scenario backends and #13 read them |
| `eval/s2_seen_fixed.yaml`, `eval/s2_unseen_fixed.yaml`, `eval/s3_seen_fixed.yaml`, `eval/s3_unseen_fixed.yaml` | the fixed-pelvis runs of S2 and S3 (`docs/evaluation.md` section 1): the file of the same scenario and split with `base: fixed`; start them with `--base fixed`, which the evaluator does not read from the file | Generated by `scripts/make_eval_configs.py` with the ten above (#78) |
